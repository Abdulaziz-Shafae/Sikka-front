# سكة | SIKKA

واجهة React عربية RTL لاستكشاف Six Flags القدية وتخطيط الزيارة. متجاوبة للجوال والكمبيوتر، بهوية سكة وألوانها، ومكوّنات shadcn/ui وحركة Motion مع احترام إعداد تقليل الحركة.

## التشغيل

تحتاج Node.js 22.13 أو أحدث وpnpm 11.

```bash
corepack enable
pnpm install
pnpm dev
```

```bash
pnpm exec tsc --noEmit
node scripts/checks/domain.cjs
pnpm build
pnpm start
```

المشروع React 19 مع Vinext/Vite، ومسارات App Router متوافقة مع Next، وWorker لعرض الصور من المصادر المعتمدة. إعدادات الاستضافة في `.openai/hosting.json`. لا توجد قاعدة بيانات أو مفاتيح مطلوبة للعرض.

## تجربة الواجهات

- الرئيسية: صور حقيقية، ألعاب بارزة، خريطة، وشرح رحلة الزائر.
- الألعاب: بحث وتصنيف حسب المنطقة والنوع، تفاصيل ومفضلة.
- الخريطة: تكبير وسحب، وطبقات الألعاب والمطاعم و٤ مصليات و١٤ دورة مياه. اختر بداية ووجهة لرسم مسار المشي التقريبي على شبكة المشروع.
- فريق سكة: صفحة لأعضاء الفريق وروابط لنكدن. الروابط غير المؤكدة تبقى غير نشطة، وتضاف في `lib/sikka-team.ts`.
- الزيارة: تفاصيل، أعضاء، ألعاب، بريكات، معاينة، ومحاكاة الدفع.
- الخطة: جدول القروب/الفرد، اعتماد، متابعة إنجاز، تقييم، وملخص الزيارة.
- الحساب والعائلة والخصوصية والإشعارات، ومعاينة إدارة الكتالوج.

ابدأ بزر «جرّب زيارة جاهزة» أو «خطّط يومك». التنقل داخل التطبيق عبر hash routes، لذلك الروابط المباشرة مثل `/#map` تعمل بدون إعدادات إعادة توجيه. الزيارات والتفضيلات محفوظة في localStorage تحت `sikka-demo-v1`؛ يمكن مسحها من الخصوصية. كلمات المرور لا تُحفظ.

## حدود النسخة والربط

هذه نسخة عرض تفاعلية. الدخول، الدفع، الدعوة المشتركة، وتوليد الخطة محاكاة محلية، ولا تنشئ حسابات أو عمليات مالية أو رسائل فعلية. أوقات الانتظار غير متصلة. الجدول المحلي يضع أنشطة متتابعة ضمن المدة المختارة؛ يقتطع الألعاب الزائدة عن المساحة المتاحة. لا يحسب أهلية ركوب حقيقية ولا ازدحامًا أو ساعات عمل أو صلاة أو مسافة انتقال دقيقة.

`lib/sikka-api.ts` يحتوي نقطة بداية لعقود API راجعتها مقابل فرع `integration/team-flows` في SIKKA عند `7fca9f36274eaaa32011ce82645bbc53aa78df33`. ليس موصولًا بحالة الواجهة. ضبط `NEXT_PUBLIC_SIKKA_API_URL` وحده لا يحوّل العرض لمنتج متصل؛ يلزم ربط الحالة والطلبات، والتحقق من DTOs والجلسة والصلاحيات وCORS، وإضافة تدفقات مصادقة ودفع حقيقية وتأكيدات من الخادم. لا تضع أسرارًا في متغيرات `NEXT_PUBLIC_`.

## البيانات والأصول

`lib/park-catalogue.json` و`lib/park-routes.json` مأخوذان من بيانات مستودع SIKKA. الكتالوج يضم 32 تجربة. شروط العمر والطول والصحة في seed بيانات مصطنعة `urn:sikka:demo`، وليست تعليمات المشغّل. مداخل الألعاب في الخريطة غير مؤكدة؛ المسار تقريبي بسرعة مشي افتراضية 70 مترًا/دقيقة. تحديد موقع الزائر لا يُرسم على الصورة قبل معايرتها ميدانيًا.

الصور الحقيقية ومصادرها معرّفة في `lib/sikka-data.ts` وتظهر في صفحة مصادر الصور. حقوقها لأصحابها، ويجب التحقق من الترخيص قبل النشر التجاري. الألعاب التي لا نملك لها صورة موثّقة تستخدم رسمًا تجريديًا واضحًا بدل إسناد صورة لعبة أخرى لها. يتطلب تحميل الصور اتصالًا بمصادرها الخارجية. التطبيق مشروع عرض مستقل، غير تابع للمشغّل.

## الملفات الأساسية

- `app/page.tsx`: الواجهات ومسار تجربة العرض.
- `app/globals.css`: الهوية والتجاوب والحركة.
- `components/sikka/park-map.tsx`: الخريطة والمحددات والمسار.
- `lib/sikka-data.ts`: ربط الكتالوج وجدولة الأنشطة المحلية.
- `lib/sikka-api.ts`: بداية طبقة الاتصال المستقبلية.
- `app/api/media/[asset]/route.ts`: وسيط صور بقائمة مصادر ثابتة.

صورة الخريطة وشبكة المسارات والمرافق من إضافة Nawaf (`Nawaf2m`) في مستودع SIKKA، commit `dd8883122031fb1d9e108897740bb3a3cc3a7875`. واجهة العرض وطبقات المرافق ومخطط المشي في هذا المستودع مبنية عليها.
